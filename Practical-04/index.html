2. Collapsible FAQ Accordion

Smooth height transition, animated expand icons, and ARIA state updates via JavaScript event delegation.

We leverage the localStorage.setItem('studenthub_theme', theme) Web API. Because localStorage provides persistent client-side key-value storage with no expiration, the selected mode is immediately re-applied on subsequent page loads without server latency.

Instead of binding separate listeners to multiple child elements, a single event listener is attached to their common ancestor (e.g., #faqAccordion). Using e.target.closest('.accordion-header'), events bubbling up through the DOM are captured efficiently, conserving browser memory.

The modal listener monitors global keydown events. If the Escape key is triggered while the modal is active, the overlay is dismissed and scroll locking is restored immediately to preserve accessibility.
