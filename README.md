## 🚀 StudentHub Project Overview

**StudentHub** is an integrated campus portal system developed across the semester. It enables students to view announcements, explore university clubs and events, register for campus workshops, view student directories, and manage their profiles. Administrators and faculty coordinators have a secure, role-protected dashboard for managing student databases, scheduling events with posters, tracking registrations, inspecting audit trails, and generating reports.

---

## 🛠️ Global Technology Stack
- **Frontend**: HTML5, Semantic Markup, WAI-ARIA, CSS3 (Custom Variables, Flexbox, CSS Grid), Vanilla JavaScript (ES6+), Canvas API
- **Backend**: PHP 8.x (Modular, Object-Oriented, PDO / Prepared Statements)
- **Database**: MySQL 8.x / MariaDB (Normalized 3NF, Foreign Keys, Stored Procedures, Triggers)
- **Web Server**: Apache (XAMPP / WAMP / LAMP)
- **Version Control**: Git & GitHub
